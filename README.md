# Furuta Pendulum State Space Modeling

This repository documents a state-space modeling practice developed for the rotary inverted pendulum (Furuta pendulum) during the Minor in Autonomy of Unmanned Aerial Vehicles at Tecnológico de Monterrey.

The practice focuses on deriving the linear state-space representation of the pendulum system from first principles and validating the resulting model against the real platform. It includes the formulation of the system equations, computation of the state-space matrices, MATLAB implementation, Simulink modeling, and comparison between the virtual model and experimental measurements.

The work was developed to understand the dynamic behavior of the rotary pendulum system in open loop and to evaluate how closely the linear model captures the response of the real plant. The results show that the model provides a useful approximation of the system dynamics, while also revealing practical deviations caused by friction, unmodeled nonlinearities, and sensor limitations.

This repository is intended to present both the theoretical derivation and the practical validation of a state-space model for an underactuated mechatronic system used in advanced control education.
